# 16 — Glossary

- **APEX:** The personal AI assistant being developed.
- **Buddy:** The owner's friendly nickname for ChatGPT; not the product name.
- **Provider adapter:** A common interface that lets APEX switch between AI providers.
- **Tool:** A controlled function APEX can invoke, such as opening an approved app.
- **Permission gate:** A policy check that decides whether a tool action is allowed.
- **Wake word:** A phrase detected to activate voice interaction.
- **Push-to-talk:** Voice capture only while the user presses/holds a control.
- **Local-first:** Keep suitable data and functions on the user's device.
- **Cloud AI:** AI inference performed by an external provider.
- **MQTT:** Lightweight messaging protocol often used for IoT devices.
- **Prompt injection:** Untrusted content attempting to manipulate an AI system into ignoring its rules.
- **ESU:** Extended Security Updates for eligible Windows versions after standard support ends.
