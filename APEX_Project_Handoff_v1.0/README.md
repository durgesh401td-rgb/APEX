## What APEX is

APEX is a personal AI assistant ecosystem for Windows PC and Android. It combines conversational AI, voice interaction, memory, productivity, controlled PC automation, supported phone integration, document understanding, web research, and IoT integration.

The design goal is a capable assistant with a calm, premium, dark interface—not a crowded sci-fi control panel.

## Important instructions for the coding agent

- Treat this pack as the source of truth. If something conflicts, stop and ask the owner.
- Begin with repository inspection and a written implementation plan. Do not immediately generate the whole application.
- Implement one milestone at a time; run and report tests after each milestone.
- Do not overwrite, delete, repartition, or reorganize the user's existing files without explicit approval.
- Never hardcode API keys, passwords, tokens, or personal credentials.
- Do not claim a feature works until it has been run and verified.
- The user has requested a guided project. Explain decisions in beginner-friendly language.
- Keep the UI dark, clean, spacious, and modular. Do not compress every feature into one screen.
- The owner has not yet approved implementation details beyond this planning baseline. Confirm before major stack changes or paid services.
